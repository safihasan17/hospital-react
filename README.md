# Hospital React — fresh template

A clean, static React + Bootstrap template (dark sidebar admin layout).
No API, no mock data, no `useEffect` — every page is plain markup you can wire up yourself.

```bash
npm install
npm run dev
```

- `src/index.css` — all template styling
- `src/views/layout` — Sidebar, Navbar, Footer
- `src/views/pages` — Dashboard + Manage / Add / Edit / Details pages for every module
- `src/routes.tsx` — all routes

Tables show an empty "No data yet." row; each Manage page has a commented example row showing where to render your data. Forms are plain uncontrolled inputs — add `useState` and your API call when you are ready.
